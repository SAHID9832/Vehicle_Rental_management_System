# MOVO — Vehicle Rental Management System

**Move Your Way.**

MOVO is a full-stack vehicle rental management web application developed as an MCA academic project. It allows customers to browse vehicles, view vehicle details, estimate rental costs, and manage their bookings. It also provides an admin dashboard to manage vehicles, customers, branches, rentals, maintenance, and invoices.

## Key Features

- **Vehicle Browsing:** Explore vehicles by category, price, and availability.
- **Vehicle Details:** View specifications, images, and rental information.
- **Booking Management:** Create bookings and manage reservations.
- **Customer Management:** Register, log in, and manage customer profiles.
- **Admin Dashboard:** Manage fleet inventory, branches, customers, and bookings.
- **Rental and Maintenance:** Track vehicle rentals, returns, and servicing.
- **Billing and Invoices:** Manage rental invoices and simulated payments.
- **DSA Laboratory:** Demonstrate data structures and algorithms through practical examples.

## Data Structures and Algorithms

The project implements four DSA phases:

1. **Linear Data Structures:** Linked List, Stack, and Queue.
2. **Trees and Graphs:** Binary Tree, Binary Search Tree, Graph, and BFS traversal.
3. **Searching and Sorting:** Linear Search, Binary Search, and Merge Sort.
4. **Algorithmic Problem Solving:** Greedy vehicle allocation based on customer requirements.

## Technologies Used

- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **Backend:** Node.js and Express.js.
- **Database:** MySQL.
- **Authentication:** JWT and bcrypt.
- **Charts:** Recharts.

## Project Purpose

MOVO aims to demonstrate how a vehicle rental business can be managed through a web application while applying data structures and algorithms to practical operations such as vehicle searching, sorting, allocation, and booking management.

## Security

Do not publish real login passwords, JWT secrets, database passwords, API keys, or private customer information in this public repository. Store sensitive configuration in environment variables and keep `.env` files out of Git.
